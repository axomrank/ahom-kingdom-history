# Ahom Kingdom History (1228–1838): saga, timeline, people, scenes, story map and lessons

> The Ahom kingdom of Assam (1228–1838) as an illustrated website: saga chapters, all 41 reigns on one timeline, people, painted scenes, short films, a story map, and 41 bilingual lessons (one per reign) for exam aspirants.

**[Live site](https://axomrank.github.io/ahom-kingdom-history/)** · **[Lessons](https://axomrank.github.io/ahom-kingdom-history/lessons/)** · [Part of AxomRank](https://github.com/axomrank)

## At a glance

- **Eight saga chapters**, all **41 reigns** on one timeline, and a catalogue of people and painted scenes
- **49 short films** with English and Assamese context subtitles
- **MAP tab:** a story-driven historical atlas with river geography, event search and reading paths
- **Crawlable reference pages** (`chapters/`, `people/`, `scenes/`, `films/`, `trails/`) with metadata and sources
- **One master CSV** (`data/ahom.csv`) feeds everything. `tools/build.py` regenerates the site data
- **Ahom Kings lessons** in [`lessons/`](lessons/README.md): 41 short bilingual lessons with 14 exercise types and spaced review, linked from the menu, from every reign on the Kings page and from each king's profile. The same app is also deployed to [ahom-lessons.pages.dev](https://ahom-lessons.pages.dev)
- Paintings, portraits and films are **modern reconstructions**, not likenesses from the period

## Quick start

```bash
python3 -m pip install -r requirements.txt
python3 tools/build.py && python3 tools/verify_site.py
python3 -m http.server 8765   # open http://localhost:8765 (lessons at /lessons/)
```

The lesson app has its own build and checks: see [lessons/README.md](lessons/README.md) (`cd lessons && python3 scripts/build.py`). `tools/package_site.py` copies its website files into the published site.

## Overview

The Ahom kingdom of Assam, 1228–1838: a website that tells its story chapter by chapter, sets out all forty-one reigns on one time line, and collects the people and painted scenes of the chronicles.

| `data/site.js` | What the website loads (generated) |
| `media/characters/` | Portraits and character sheets, one folder per person, with `thumb/` copies |
| `media/scenes/` | Scene paintings by era, with `thumb/` copies |
| `media/faces/` | Face portraits cut from the character sheets (generated) |
| `media/reels/` | The short films, compressed, each with a poster frame |
| `research/` | Research notes per person and per batch, and the reel scripts |
| `tools/` | Content generation, reel preparation, validation and deployment packaging |
| `chapters/`, `people/`, `scenes/`, `films/`, `trails/` | Generated, crawlable reference pages with metadata and sources |
| `images/assam/` | Generated scenes of everyday life, villages and objects (originals, with notes) |
| `images/referance/` | Real-photograph reference library for making images; not shown on the site |

| `data/map-sites.json`, `data/map-stories.json` | Geographic catalogue and editorial event/route bindings for MAP |

`archive/` (originals, full-size reels, backups) and `incoming/` stay on your computer and are not in git.

## Changing the content

1. Edit `data/ahom.csv` (people, scenes, images) or `data/eras.json` (the saga chapters).
2. If you added a character sheet, cut its face portrait: `python3 tools/make_faces.py`
3. If you added images under `images/assam/`, list them in `tools/build_life.py` and run it
4. Rebuild the data: `python3 tools/build.py`

Install the build dependency with `python3 -m pip install -r requirements.txt`.
Run `python3 tools/verify_site.py` before publishing. Pages deployment runs both commands
and stages only public assets with `python3 tools/package_site.py _site`.

The film library has 49 distinct shots: the original 27 and 22 additional clips in
`media/reels/clean2/`. The 21 files in `Clean/` are alternate encodes or shorter cuts,
not additional shots. `research/reel-inventory.json` records every file and selection.
`python3 tools/prepare_reels.py` regenerates the editorial reel catalogue and posters
(requires ffmpeg/ffprobe); then run the regular content build. This leaves footage intact.

All 49 films have optional English and Assamese context subtitles, written scene
descriptions and links to historical context. The subtitles describe the scene;
they do not transcribe speech. `data/reel-context.json` holds the Assamese titles.
Existing scripted Assamese lines and English translations are labelled as scripts, not audio
transcripts. Verified speech captions are still needed; do not derive them from prompts.
The MAP tab is a story-driven historical atlas: narrative on the left, animated river
geography on the right, with linked place names, event search, reading paths, playback,
camera movement and a sequence scrubber. The 39 river paths come from the local APP
catalogue (`assets/maps/assam.json`, imported from `Dist + Rivers (simplified).kmz`).
Optional Assam, India, district and International boundary pills are off by default and toggle independently.
International loads Natural Earth's 258 country/territory outlines on demand, with a world
overview. A Sukaphaa journey shortcut opens an animated migration overview and five-stage
reading path from Mong Mao to Charaideo (1215–1253), with source-linked qualifications.
District lines retain the local source's 33-unit vintage; Assam's outline is dissolved from
the original KMZ polygons. India uses DataMeet's Survey of India derived country dataset.
These are modern reference layers, not historical borders. Provenance and licenses are in
`assets/maps/README.md` and `assets/maps/boundaries.json`. The 77 reference coordinates in `data/map-sites.json`
come from APP's `content/entities.json` (re-import with `tools/import_map_sites.py FILE`).
`tools/map_events.py` binds literal place/river mentions to events; `data/map-stories.json`
defines explicit connections and editorial qualifications. Fourteen events have animated
connections; 112 events name mappable places or rivers. Other records retain valley context.
River journeys follow the stored Brahmaputra geometry between reference points. Connections
are interpretive links between places, not claims about exact historical tracks. All map
animations respect reduced-motion preferences; playback is opt-in and stops on navigation.
The old `#/explore` URL opens MAP for compatibility. Share an event with `#/map?event=AHOM-209`.

The build stops and lists the problem if a row names an unknown person or an image file that is missing.

## For AI agents and contributors

For the lesson app, read [lessons/AGENTS.md](lessons/AGENTS.md) and run its commands from `lessons/`. For the site, read [AGENTS.md](AGENTS.md) for the image-creation and architecture rules. Never hand-edit generated files (`data/ahom.json`, `data/site.js`, and the reference page folders). Edit `data/ahom.csv` or `data/eras.json`, then rebuild.

Commit as the `axomrank` account. Keep changes small and reviewable, and run the repository's checks before pushing.
